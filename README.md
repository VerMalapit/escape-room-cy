# 🔒 System Breach — MATI Computing Escape Room

A 9-room virtual escape room covering all Fundamentals of Computing topics, with a boss room featuring Sir Oliver.

## 🚀 Deploy in 5 minutes (GitHub Pages)

### Step 1 — Upload to GitHub
1. Go to [github.com](https://github.com) and sign in (or create a free account)
2. Click **New repository** → name it `escape-room` → click **Create repository**
3. Upload all these files (drag & drop the whole folder, or use the instructions below)

### Step 2 — Enable GitHub Pages with GitHub Actions

1. In your repo, go to **Settings → Pages**
2. Under **Source**, select **GitHub Actions**
3. Create the file `.github/workflows/deploy.yml` (already included in this repo)

### Step 3 — Push & share
Once you push, GitHub automatically builds and deploys the site.  
Your live URL will be: `https://YOUR-USERNAME.github.io/escape-room/`

Share that link with students — multiple teams can open it simultaneously on their own devices.
